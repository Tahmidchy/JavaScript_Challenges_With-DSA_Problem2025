🚀 JavaScript Challenges & DSA Problem Solving (2025)

📖 About This Repository

Welcome to my JavaScript Core Concepts, Problem Solving, and Data Structures & Algorithms (DSA) repository!

This repository documents my continuous journey of mastering JavaScript from fundamental building blocks to advanced asynchronous patterns and algorithmic problem-solving. A significant portion of the core concepts, hands-on exercises, and logic-building techniques here are inspired by and practiced from Jhankar Mahbub's JavaScript Book along with real-world coding challenges.

🎯 Objectives

Build a rock-solid foundation in Core & Modern JavaScript (ES6+).

Master logic-building techniques and algorithmic problem-solving.

Understand JavaScript under-the-hood mechanisms (this context, Prototypal Inheritance, Closures, Promises, Event Loop).

Maintain clean, readable, and well-structured code practices.

📂 Repository Structure & Topics Covered

The codebase is organized systematically by topic for easy navigation and revision:

1. Fundamentals & Control Flow

Variables & Data types: Primitive vs. Reference types, type coercion, and variable scoping.

Comparison operators & if-else statements: Conditional logic and decision-making flows.

Loop Problem: Iterative problem-solving (for, while, for...of, for...in).

2. Data Structures & Manipulation

Array & Array Method: Deep dive into .map(), .filter(), .reduce(), .find(), .slice(), .splice(), etc.

String_Methods: String parsing, manipulation, and formatting challenges.

Object_Problem & Building Object Method: Object creation, property manipulation, and custom methods.

Data Acess: Accessing deeply nested objects and arrays safely (Optional Chaining, Nullish Coalescing).

3. Functions, OOP & Modern JS (ES6+)

Functions: Function declarations, expressions, arrow functions, callbacks, and higher-order functions.

ES6_And_Modern_JavaScript & Destructuring_JavaScript: Spread/rest operators, template literals, and array/object destructuring.

This Context: Implicit, explicit (call, apply, bind), default, and arrow function this bindings.

Class: ES6 Classes, constructors, prototypal inheritance, and prototype chains.

4. Asynchronous JS & Problem Solving

Json_Face_promise & JSON_Face_Promise2: Working with JSON data, Promises, async/await, and API handling.

Error Validation: Defensive programming, input validation, and try...catch error handling.

Logic_build_up_technique & Data structure_Algorithm_JS: Core DSA implementations, time/space complexity awareness, and algorithmic challenges.
